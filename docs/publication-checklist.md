# Publication checklist

Before publishing or linking new content:

- [ ] Check for access codes.
- [ ] Check for response URLs.
- [ ] Check for internal links.
- [ ] Check for private emails.
- [ ] Check for participant identifiers.
- [ ] Check for unapproved PDFs.
- [ ] Check that download links point only to approved public files.
- [ ] Check that invitation-only materials are listed without public `href` values.

Anything committed to this repository may become public. Keep controlled materials outside the repository and distribute them only through approved channels.
