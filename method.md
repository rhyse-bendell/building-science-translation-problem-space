# Group Concept Mapping Method

## What is Group Concept Mapping?

**Group Concept Mapping (GCM)** is a structured method for eliciting, organizing, rating, and interpreting stakeholder perspectives. Participants generate statements about a complex problem, sort those statements into meaningful groups, rate them on key dimensions, and help interpret the resulting maps and themes.

## How GCM is used in this project

The project uses GCM to develop a stakeholder-informed view of the science translation problem space. Input from participants across defense, industry, and academia will contribute to the project's maps, framework, priority areas, and leverage points.

## Participant activities

Participants generate statements, sort statements into meaningful groups, rate them on key dimensions, and help interpret maps and themes. Activity-specific instructions will explain what input is requested during each project stage.

## From input to maps and themes

The research team prepares stakeholder-generated statements for sorting and rating. Analysis of those responses produces maps and themes that participants help interpret. This structured process connects participants' input to the resulting project products.
