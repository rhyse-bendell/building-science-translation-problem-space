# Local private-materials example

The real `_private/` directory is ignored by Git and may be used locally to organize:

- study access code notes
- response platform links
- internal routing notes
- private participant documents
- draft recruitment language
- source documents not approved for public posting
- internal meeting notes

**Do not commit the real `_private/` folder.** Do not place real access codes or study links in Markdown pages, JavaScript, YAML data files, or GitHub Actions workflows.

If participants need a private link or code, distribute it directly through approved channels such as email, GroupWisdom, Qualtrics, REDCap, UCF-managed storage, or another controlled-access system.
